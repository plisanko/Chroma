## 3. Intended use

Chroma Client is intended for lawful, legitimate end-user use of Minecraft: Java Edition. It creates and launches isolated instances, obtains official Mojang metadata and game files, supports selected mod loaders, and manages local mods and related files.

Chroma Client does not bundle or redistribute paid Minecraft files.
